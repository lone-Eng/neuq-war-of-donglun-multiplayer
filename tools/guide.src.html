01这是什么游戏

一副 160 张的牌堆，一群各有心思的老师学生。有人要护住院长，有人要把他拉下马， 有人只想活到最后 —— 而开场时你只知道自己的身份。

每一轮你都在做同一件事：猜出谁是敌人，然后把牌打在他身上。 但牌打出去会暴露立场，救人也会暴露立场，什么都不做又会被当成滑水 —— 这就是这个游戏全部的乐趣。

和三国杀什么关系 玩法骨架（回合六阶段、距离与攻击范围、判定、濒死救援、无懈可击式的对抗链）都从三国杀来， 但牌名、角色、技能全部换成了校园生活。你在三国杀里会的东西，这里八成都用得上。

02先把它跑起来

自己玩 / 几个人凑一个屏幕

双击 index.html 就能玩。不用装东西、不用联网、不用服务器。

手机上玩

把 东秦杀-mobile.html 发到手机上（微信发给自己就行），用浏览器打开。 这一个文件里装着全部内容，不依赖任何其它文件。

多人在线联机

房主双击 start-server.bat，窗口里会打印一个网址，其他人连同一个 WiFi 打开它即可。 详见 第 9 节。

开局洗混身份牌，每人一张。除了院长，谁都不知道别人是什么身份 —— 包括你旁边那位一直说"我是学生"的人。

04一回合做什么：六个阶段

从院长开始，按座位顺序轮流。轮到你时，自动走这六步：

回合开始
触发"回合开始时"的技能（比如董伦【轮值】摸一张弃一张）。
查考勤（判定）
如果你身上贴着通知栏里的延时牌，现在翻牌堆顶来判定它是否生效。 最先贴上去的最后结算。辅导员签字只在这个时刻才能抵消延时牌。
摸牌
摸两张。
出牌 ← 你的主要操作
想打什么打什么，直到你点"结束出牌阶段"。限制见下一节。
弃牌
手牌要弃到不超过你的当前体力。血越少，能存的牌越少。
结束
清掉本回合的状态标记，轮到下一个人。
出牌阶段的硬限制
  • 点名类牌每回合只有 1 张（上课点名 / 公开处刑 / 雷同警告 三者共用这个额度）——装上武器【点名册】才能不限张数
  • 延时牌（手机没电 / 饭卡没钱 / 论文查重）每回合只能放 1 张
  • 每名角色的主动技各限 1 次
  • 请假条不限张数（只要血没满）

05牌怎么用

06必须懂的八个词

距离

座位相邻就是距离 1，隔一个人是 2，以此类推。骑上 +1 坐骑会让别人看你更远， 骑 −1 坐骑会让你看别人更近。距离最小是 1，再近也不会变成 0。

+1 和 −1 坐骑是两个独立栏位 —— 可以同时骑一匹，两个修正各算一次； 装第二匹 +1 只会顶掉第一匹 +1，不会碰你的 −1。所以装备栏一共是四格： 武器 / 防具 / +1 坐骑 / −1 坐骑。

攻击范围

没装武器时攻击范围是 1 —— 也就是说你只能打到左右相邻的两个人。 想打远处的人，先弄把武器。攻击范围 ≥ 距离才能指定他。

点名类牌

【上课点名】【公开处刑】【雷同警告】三种牌共用每回合 1 张的额度， 都能被【代课】抵消。其中后两种是属性伤害（火 / 雷），所以【雨衣】挡不住它们。

查考勤（判定）

翻开牌堆顶一张牌作为"抽签牌"，看它的花色。红色 = ♥♦，黑色 = ♠♣。 很多技能和延时牌都靠它决定成败 —— 这是这个游戏里最大的随机来源。

通知栏

延时牌不是立刻生效的，而是贴在对方角色的"通知栏"里，等他的回合开始时才结算。 后贴的先结算。你可以长按那些小卡看效果。

响应窗口

你被人点名时，会弹窗问你要不要打出【代课】。这时候打出去就能免除伤害。 类似的还有：有人用事件牌时会问全场要不要打【辅导员签字】把它取消掉。

濒死

体力归零不会立刻死，先进入濒死：本人可以先自救（打请假条 / 红牛）， 救不回来再由其他人轮流救援。救人是公开的，所以要不要救，本身就是一次表态。

身份推断

游戏里没有"验人"的牌，你只能靠行为推理：谁打了院长（更像学生）、谁救了院长（更像教务）、 谁一直不打人（可能是卧底在苟）。电脑对手也是这么想的。

07上手三步

第一步：第一次玩就用这套设置

设置选什么为什么
人数5 人攻守最均衡，一局 30–40 分钟
身份模式A 随机身份不用协商，直接体验推理
选角候选3 选 1有选择权，又不会挑花眼
保护轮开第一圈没人会死，给你时间看懂局面

第二步：出牌就三个动作

点牌 → 点人 → 出手 ① 点手牌里描着金边的那张（金边表示现在能用）
② 棋盘上描绿边的角色就是能选的目标，点他
③ 底部出现一条操作条，点「出手」（或者按 Enter）
不需要选目标的牌（比如请假条、借笔记）点一下就直接结算了。

第三步：看不懂就长按

长按任何一张牌（电脑上右键也行）→ 弹出完整牌面：类型、目标、距离、效果、限制、结算顺序。
长按任何角色 → 弹出他的两个技能全文、装备、通知栏、以及"他离你多远"。

09联机怎么玩

开一局

  1. 房主双击 start-server.bat（第一次会弹 Windows 防火墙提示，必须点"允许访问"）
  2. 窗口里会打印一个地址，标着「<<< 一般就是这个」。房主自己开 http://localhost:8080/
  3. 其他人连同一个 WiFi，打开那个地址（手机上直接用浏览器开就行）
  4. 房主点「联机对战 → 创建房间」，拿到 4 位房间号
  5. 房主点「复制邀请链接」发到群里 —— 别人点开就直接进房间，不用手抄地址和房间号
  6. 房主点「开始游戏」，各自选角，开打

人不够没关系：空座位由电脑补齐，所以 3 个人也能开一局 5 人局。 新来的人会自动变成旁观，看得到全场但看不到任何人的手牌和身份。

联机时才有的东西

  • 快捷语（顶栏 💬）：8 句预设 + 自由输入，说的话会在角色面板上冒气泡
  • 思考读秒：轮到真人时全场都看得到"他在想"，掉线或超时会自动由电脑接管
  • 掉线托管：有人掉线，房主日志会提示，那个座位转给电脑
  • 刷新不掉线：中途刷新页面会自动回到原座位

几个要注意的

情况会怎样
房主关掉了页面 / 关了服务器窗口这局停摆，但其他人屏幕上会弹「我来接手」，点一下能用存档接着打
房主把浏览器切走 / 最小化浏览器会节流后台标签页，全桌会明显变慢。房主尽量保持页面在前台
别人打不开网页九成是防火墙没允许；或者不在同一个 WiFi；或者地址用错了（试另一个）
手机连不上确认手机连的是 WiFi 不是流量

10常见问题

为什么我打不出第二张上课点名？

点名类牌每回合只有 1 张（上课点名 / 公开处刑 / 雷同警告 一起算）。 想连打，唯一办法是装上武器【点名册】。

为什么选不中那个人？

多半是距离超过攻击范围。没武器只能打相邻的人；想要够得着，先装武器， 或者骑 −1 坐骑把自己和别人的距离拉近。

【学生证】挡得住【雷同警告】吗？

能。它按"黑色点名类牌"判定，而雷同警告全黑。但它挡不住【公开处刑】—— 公开处刑全红。

【辅导员签字】什么时候能打？

只有牌真正起作用的那个瞬间：
· 普通事件牌 —— 使用时
· 群体牌（随堂测验 / 突击查寝）—— 对每个目标分别问，取消一个不影响别人
· 延时牌（手机没电 / 饭卡没钱 / 论文查重）—— 只在回合开始查考勤时问，刚贴上去的时候不能取消

体力归零就死了吗？

不会，先进濒死。你自己可以先用请假条 / 红牛自救；救不回来，其他人会依次被问要不要救你。 都没人救才真的出局，然后翻身份牌。

怎么知道自己该打谁？

看身份。你是学生就打院长；是院方就清场；是卧底就让别人先打院长、自己留到最后。 不确定的时候，跟着"谁在打院长"这条线索走 —— 打院长的人大概率是学生。
